🔧 Remote Shutdown Setup Guide

Why Remote Shutdown Fails

Remote shutdown requires specific Windows permissions and network configuration. Common issues:

  • Access Denied - Your account lacks admin rights on target computer
  • Network Path Not Found - Computer is offline or firewall is blocking
  • RPC Server Unavailable - Remote Registry service not running

✅ Requirements for Remote Shutdown

  1. Administrator Privileges
    • Your Windows account must have administrator rights on the target computer
    • You must be logged in with an admin account
  2. Network Connectivity
    • Target computer must be online and reachable
    • Both computers must be on the same network or have proper routing
  3. Windows Firewall Configuration
    • Remote Shutdown must be allowed through firewall
    • File and Printer Sharing must be enabled
  4. Remote Registry Service
    • Remote Registry service must be running on target computer

🛠️ Step-by-Step Setup (On Target Computers)

Step 1: Enable Remote Registry Service

  1. Press Win + R, type services.msc, press Enter
  2. Find "Remote Registry" in the list
  3. Right-click → Properties
  4. Set "Startup type" to "Automatic"
  5. Click "Start" to start the service
  6. Click "OK"

Step 2: Configure Windows Firewall

  1. Press Win + R, type wf.msc, press Enter
  2. Click "Inbound Rules" on the left
  3. Find and enable these rules:
    • "Windows Management Instrumentation (WMI-In)"
    • "Remote Shutdown (RPC)"
    • "File and Printer Sharing (SMB-In)"
  4. Right-click each rule → Enable Rule

Step 3: Grant Admin Rights (If Needed)

  1. Press Win + R, type lusrmgr.msc, press Enter
  2. Click "Groups" → "Administrators"
  3. Click "Add" and add your user account
  4. Click "OK"

🧪 Testing Remote Shutdown

Test from Command Prompt (run as Administrator):

shutdown /s /m \\192.168.1.100 /t 60 /c "Test shutdown"

This will schedule a shutdown in 60 seconds. To cancel:

shutdown /a /m \\192.168.1.100

🔍 Troubleshooting

Error: "Access is denied"

  • Verify you're logged in as administrator
  • Check Remote Registry service is running on target
  • Ensure your account has admin rights on target computer
  • Try using domain admin account if on domain network

Error: "The network path was not found"

  • Verify target computer is online (check power report)
  • Ping the IP address to confirm connectivity
  • Check firewall isn't blocking SMB (port 445)

Error: "The RPC server is unavailable"

  • Start Remote Registry service on target computer
  • Enable "Remote Shutdown (RPC)" firewall rule
  • Check Windows Firewall isn't blocking RPC

⚠️ Alternative: Group Policy (Domain Networks)

For domain networks, IT administrators can configure these settings via Group Policy:

  • Computer Configuration → Windows Settings → Security Settings → System Services → Remote Registry
  • Computer Configuration → Windows Settings → Security Settings → Windows Firewall
