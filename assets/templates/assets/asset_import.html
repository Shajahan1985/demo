Instructions

Upload an Excel file (.xlsx or .xls) containing asset data to import multiple assets at once.

Required Columns:

  • asset_tag - Unique identifier (e.g., BIDC123)
  • system_type - Must be one of: Desktop, Laptop, All-in-One PC
  • operating_system - Must match an existing OS name in the system
  • ip_address - Valid IPv4 address that is not already assigned

Optional Columns:

  • particulars - Additional details about the asset
  • assigned_to - Name of the person assigned to this asset
  • team - Must match an existing team name in the system
  • warranty_expiration - Date in YYYY-MM-DD format
